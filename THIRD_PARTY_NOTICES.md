# Third-party assets included in chamberviz

| Asset | Source | License |
|---|---|---|
| Round flags (`assets/flags/round`) | HatScripts/circle-flags | MIT |
| Rectangular flags (`assets/flags/rect`) | lipis/flag-icons | MIT |
| Icons (`assets/icons/tabler-icons*.ttf`) | Tabler Icons (tabler.io) | MIT |
| Noto Sans, Noto Sans Arabic, Noto Serif Display fonts | Google Noto project | SIL Open Font License 1.1 |
| Amiri Bold font | Amiri project | SIL Open Font License 1.1 |
| World maps (`assets/maps`) | Natural Earth | Public domain |
| Country names in Arabic/English (`assets/countries.json`) | umpirsky/country-list + Natural Earth | MIT / public domain |

The file `assets/logos/demo_logo.png` is a neutral placeholder made for the examples.
It is **not** the Amman Chamber logo; add the real one with `cv.set_default_logo(...)`.
